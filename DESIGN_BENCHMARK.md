# Design Benchmark

Date: 2026-04-26

## GitHub design references

These open-source projects informed the design pass:

- LangUI: polished AI chat surfaces, prompt cards, and assistant-first interaction patterns.
- shadcnspace: clean component blocks, balanced spacing, accessible controls, and production-ready app layouts.
- shadcn dashboard starters: dashboard structure, cards, tables, forms, dark mode, and responsive admin layouts.
- Horizon UI: premium dashboard cards, metric panels, sidebar/topbar polish, and calm product density.
- Open WebUI: AI chat workflow, model/provider controls, assistant ergonomics.
- Dify: agent workflow cards, tool catalog, production AI app framing.
- Onyx: enterprise AI search/RAG style, source-backed answer panels, workspace feel.

## Applied direction

The app suite now uses a shared polish layer:

- Neutral dark foundation with app accents.
- Consistent 8px cards and panels.
- Stronger focus states for keyboard and accessibility.
- Better button, chip, input, table, and dashboard surfaces.
- Mobile-safe touch targets.
- Subtle premium background texture without relying on decorative blobs.
- Reduced-motion handling for accessibility.

This keeps each app's existing product identity while making the whole suite feel more cohesive and current.
